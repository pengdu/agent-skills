# File and Media Processing

## 触发条件与不适用场景

在请求涉及大文件上传、对象存储、转码、缩略图、视频播放或 CDN 分发时使用。不适用于只存放少量结构化元数据的请求。

## 输入清单

- 文件大小、格式、上传可靠性、地域和保留期。
- 预览、转码、播放、下载与分享要求。
- 访问控制、合规、清理和成本目标。

## 决策流程

1. 大文件采用分块或 multipart 直传对象存储。
2. 元数据与对象内容分离，使用稳定对象键和可追踪上传会话。
3. 转码、缩略图和内容审核走异步处理队列。
4. 读取经 CDN 或签名 URL 交付，并在权限撤销时控制有效期。

## 权衡与失败模式

- 直传降低应用服务器带宽，但要求严格签名和上传会话治理。
- 异步处理提高吞吐，但产生预览不可用窗口和积压风险。
- 防止分块重试损坏、孤儿对象、转码积压、越权访问和 CDN 陈旧内容。
