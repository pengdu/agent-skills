# Search and Indexing

## 触发条件与不适用场景

在请求涉及全文搜索、倒排索引、召回、排序、过滤或索引新鲜度时使用。不适用于仅按主键精确读取的请求。

## 输入清单

- 检索字段、过滤条件、排序目标和召回质量。
- 索引更新延迟、文档规模、查询 QPS 和重建窗口。
- 分词、语言、权限过滤和删除语义。

## 决策流程

1. 全文检索使用倒排索引；精确主键查询保留在主数据库。
2. 按 term 或文档分片，按热点和查询模式选择路由。
3. 通过异步索引管道解耦主写路径，定义索引新鲜度 SLO。
4. 将召回、过滤、排序和权限校验分层，并提供重建路径。

## 权衡与失败模式

- 异步索引降低写延迟，但产生可见性延迟。
- 更丰富的索引提升查询能力，但增加写放大和存储成本。
- 防止索引新鲜度失控、分词不一致、热点 term、查询放大和重建失败。
