# Access Control

## 触发条件与不适用场景

在请求涉及资源分享、租户、角色、访问权限、撤销、签名 URL 或审计时使用。不适用于无用户隔离的公开静态内容。

## 输入清单

- 主体、资源、操作、共享范围、继承和默认策略。
- 多租户边界、权限变更频率、缓存与撤销时效。
- 审计、合规、外链和临时访问需求。

## 决策流程

1. 使用主体-资源-权限关系表达授权，明确 allow/deny 优先级。
2. 在资源读取、下载令牌和签名 URL 发放前校验权限。
3. 权限变更发布失效事件，缓存使用短 TTL 或版本校验。
4. 对跨租户访问、外链和管理员操作保留不可变审计记录。

## 权衡与失败模式

- 预计算权限提高读取速度，但撤销传播更复杂。
- 细粒度 ACL 灵活但关系量和查询成本上升。
- 防止默认放行、权限缓存陈旧、共享循环、租户越界和审计缺失。
